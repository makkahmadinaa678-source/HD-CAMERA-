# HD Camera - Application Kaameeraa Qulqullina Olaanaa

## Waan App kun Godhu
- CameraX (teeknooloojii Google) fayyadamee suuraa **qulqullina olaanaa** ni kaasa (CAPTURE_MODE_MAXIMIZE_QUALITY)
- Suuraa erga kaafamee booda **enhancement** (saturation + sharpening) ofumaan ni godha - kunis phone gatii xiqqaa irrattis suuraa akka bareedaa fi qulqulluu ta'e argamsiisa
- Kaameeraa fuulduraa fi duubaa gidduu jijjiiruu (front/back switch)
- Suuraa kaafame gara Gallery/Photos keetti ni kaaya (Pictures/HDCamera folder)

## Akkamitti Itti Fayyadamtu (Android Studio barbaachisa)

1. **Android Studio** bilisaan buufadhu: https://developer.android.com/studio
2. Folder "HDCamera" kana Android Studio keessatti bani (Open an existing project)
3. Gradle sync xumamuu eegi (interneetii barbaachisa - dependency-wwan ofumaan ni buufama)
4. Bilbila kee (yookiin emulator) qunnamsiisi, "Run" (▶) tuqi
5. Bilbila kee irratti app-n ni bane - hayyama kaameeraa gaafatu, "Allow" jedhi

## Fuula Dabalataa Dabaluuf (Yaada Gara Fuulduraa)
Yoo dabalataan barbaadde, kanneen armaan gadii dabaluu dandeenya:
- Filter dabalataa (black & white, vintage, fi kkf)
- Zoom pinch-to-zoom
- Flash on/off toggle dhugaa
- Timer (3s, 10s)
- Suuraa fi vidoo gidduu jijjiiruu (Video recording)

Kamiyyuu yoo dabaluu barbaadde, naaf himi!
